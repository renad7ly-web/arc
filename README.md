# الأرشيف

موقع أرشيف بسيط (HTML ثابت) يعمل على GitHub Pages.

## التشغيل
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل هذه الملفات.
2. من Settings ← Pages اختر Branch: `main` والمجلد `/ (root)`.
3. يظهر الموقع على `https://اسم-المستخدم.github.io/اسم-المستودع/`.

## إضافة ملفات
ضع الملف داخل مجلد السنة: `files/2025/اسم_الملف.pdf` (من زر Add file ← Upload files في GitHub).
بعد الرفع يعمل GitHub Action تلقائيًا ويحدّث `archive.json`، ويؤخذ العنوان من اسم الملف
(الشرطة السفلية والشرطة تتحول إلى مسافة). يظهر الملف في الموقع خلال دقيقة تقريبًا.

لتحديث الفهرس يدويًا: `python3 build_index.py`

## ملاحظات
- مستودع GitHub العام يعني أن الملفات يراها أي شخص. للملفات الداخلية استخدم مستودعًا خاصًا مع خطة تدعم Pages الخاصة.
- حجم الملف الواحد على GitHub حتى 25 ميجابايت من واجهة الويب (100 ميجابايت عبر git).
